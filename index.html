1. Pipeline source

Dataset construction

The Archive of Formal Proofs contains proof scripts but not proof states: the intermediate goals a tactic acts upon exist only inside Isabelle during checking. These tools recover them by driving Isabelle over the Language Server Protocol, emulating an interactive editor.

FilePurpose
src/afp_harvest.py Main extraction tool. Lexes Isar outer syntax, computes cursor positions, drives Isabelle over LSP, records the proof state at each position. Includes a 35-assertion offline test suite (--self-test) and a static segmentation check (--show-blocks). This is the version that produced the reported corpus; see the README for one known limitation identified after extraction completed.
src/panel_text.py Converts Isabelle's HTML panel output back to plain text. Required because the plain-text rendering path fails to serialise in the Isabelle revision used.
src/split_entries.py Stratified train/test partition over AFP entries, sampled within strata so both partitions span comparable subject matter.
src/merge_shards.py Combines parallel extraction output; checks for duplicates, missing shards, coverage, and test-set leakage.
src/validate_dataset.py Quality checks on extracted data: positional alignment against source, segmentation consistency, and aggregate distributions.
src/prepare_dataset.py Converts proof states into prompt/target training pairs, with filtering, deduplication and left-truncation of context.

Training and evaluation

FilePurpose
src/train_sft.py Full-parameter fine-tuning of Qwen2.5-Coder-7B with FSDP sharding. Loss is masked to the completion only.
src/eval_generate.py Per-step evaluation: generates the next command for each held-out position and scores exact match, command match and per-command accuracy.
src/proof_completion.py Proof-completion evaluation. Deletes a held-out theorem's proof and regenerates it from scratch, one command at a time, with Isabelle in the loop. A theorem counts as proved only when the kernel accepts the result.
tools/compare_completion.py Checks that two proof-completion runs attempted the same theorems, and reports the score on the common set. A completion figure is not meaningful unless the denominators match.
tools/probe_state.py Standalone diagnostic for the Isabelle state-panel LSP channel; used during development to isolate protocol problems.

Cluster job scripts

FilePurpose
harvest_array.sbatch Parallel extraction as a 32-shard Slurm job array.
train.sbatch Fine-tuning across 3×A100 80GB.
eval.sbatch Per-step evaluation.
completion.sbatch Proof-completion evaluation.
requirements.txt Pinned Python environment.

2. Data artefacts

Corpus partition

These files are the record of exactly which AFP entries were held out. The partition was generated from a fixed seed and applied before extraction, so held-out entries were never processed. Without these files the evaluation cannot be reproduced or verified.

FileContents
split_hol/train_entries.txt 243 AFP entries used for training.
split_hol/test_entries.txt 61 held-out entries used for evaluation.
split_hol/split_report.txt Stratification summary: entries, files and size per partition.

Test fixture

FileContents
testbed/thys/Sanity/Sanity.thy Hand-written theory importing only Main, used to verify the extraction pipeline independently of AFP session heaps.
testbed/thys/Sanity/ROOT Session declaration for the fixture.

3. Results

Raw model outputs, one JSON object per line. Each record contains the reference, the model's prediction, and the scoring outcome.

FileContents
results/completion_final.jsonl Proof completion, fine-tuned model. 20 held-out theorems; every generated command and Isabelle's verdict. 4 proved, of which 3 fall in the set the base model also attempted.
results/completion_base.jsonl Proof completion, base model. Same seed and budget; 19 of the 20 theorems reached. 0 proved.
results/test_final_full.jsonl Per-step predictions, fine-tuned model, all 70,242 held-out pairs.
results/test_final.jsonl Per-step predictions, fine-tuned model, 10,000-pair sample.
results/test_base.jsonl Per-step predictions, base model, same 10,000-pair sample.
results/val_final.jsonl Validation predictions, epoch-2 checkpoint.
results/val_epoch1.jsonl Validation predictions, epoch-1 checkpoint. Used for the checkpoint-selection comparison.
results/training_history.json Complete training history: training and validation loss at every logged step across both epochs. Evidence for the checkpoint-selection comparison.
results/completion_run_log.txt Full log of a proof-completion run: every command the model generated and Isabelle's response, step by step.
